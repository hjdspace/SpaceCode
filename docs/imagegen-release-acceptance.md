## 1. 设置与技能播种

### S1 免安装技能

- **点什么**：启动应用，等待 `imagegen` 内置技能播种完成。
- **该看到什么**：`~/.claude/skills/imagegen/` 与 `~/.pi/agent/skills/imagegen/` 下都存在 `SKILL.md` 及脚本，用户从未手动安装。
- **修复前是什么**：需要用户自己把技能目录拷进引擎技能目录，否则模型不知道有生图能力。
- **本轮**：PASS。两个引擎的技能目录均已存在且内容完整。

### S2 设置分区

- **点什么**：侧栏齿轮 → 设置 → **生图模型**。
- **该看到什么**：副标题「配置生成图片用的模型。配好后直接对 Agent 说「画张图」即可，无需安装任何东西。」；分组「供应商与模型」下依次是 **供应商、协议方言、Base URL、API Key、模型名、关闭供应商水印**；API Key 输入框占位「已配置，留空则沿用；填新的即覆盖」。
- **修复前是什么**：设置里没有生图分区，只能改配置文件。
- **本轮**：PASS。字段与文案均符合；当前配置为供应商「自定义」、方言「OpenAI Images（支持改图）」、模型 `agnes-image-2.5-flash`、Base URL `https://apihub.agnes-ai.com/v1`，API Key 已配置且不回显。

### S3 暗色主题下的原生下拉

- **点什么**：切到深色主题 → 分别展开「供应商」「协议方言」两个原生 `<select>`。

- **修复前是什么**：Chromium 原生下拉弹层不继承祖先 `color-scheme`，Windows 上必现浅色弹层配浅色文字。
- **本轮**：PASS。原生弹层是独立 HWND，逐个捕获确认深底浅字，无不可读项。

## 2. 生成链路

### S5 文生图

- **点什么**：对 Agent 说「画一张……」，在授权卡上点「允许一次」。
- **该看到什么**：卡片显示缩略图、尺寸、实际模型名；文件落在 `<workspace>/outputs/imagegen/`；产物面板同步出现。
- **修复前是什么**：模型自称不能画图，或只能口头描述。
- **本轮**：真实供应商调用 PASS。用本机已配置的 `custom` / `openai` 方言直连真实端点生成一张，返回 `model=agnes-image-2.5-flash`、`1024x1024`、660199 字节，耗时约 12s。聊天内的授权卡与产物面板联动未在本轮执行（见 §3）。

### S6 授权闸门

- **点什么**：首次生图看卡；选「允许一次」→ 同会话再画一次；换新会话再画。
- **该看到什么**：卡片写清供应商、模型、张数与 prompt；「允许一次」只放行本次；本会话内后续调用不再弹卡；新会话重新询问；「拒绝」时零请求、零文件、工具返回拒绝。
- **修复前是什么**：没有宿主闸门，工具拿到参数就直接出站计费。
- **本轮**：单测覆盖四种放行/拒绝路径与「本会话总是允许」的作用域；真实会话交互未执行。

### S7 完全信任模式

- **点什么**：打开「完全信任」后再画图。
- **该看到什么**：不弹卡直接生成；关掉后恢复逐次询问。
- **修复前是什么**：不存在该模式，所有调用都要点卡。
- **本轮**：单测覆盖；真实切换未执行。

### S8 授权卡看门狗

- **点什么**：触发授权卡后 5 分钟不操作。
- **该看到什么**：卡片自动关闭，工具返回取消，不留下永远挂起的调用。
- **修复前是什么**：无人应答的卡片会一直挂着，会话无法收尾。
- **本轮**：常量为 5 分钟、单测覆盖超时关闭；未真实等待 5 分钟。

### S9 灯箱与打开所在文件夹

- **点什么**：点缩略图 → 按 Esc；点「打开所在文件夹」。
- **该看到什么**：全屏灯箱显示大图，Esc 关闭；按钮在支持的平台把文件定位到资源管理器。
- **修复前是什么**：卡片只显示路径文本，用户要自己去找文件。
- **本轮**：真实组件原型（`docs/prototypes/imagegen-inline-preview.html`）+ 浏览器验证 PASS：缩略图渲染、灯箱打开/Esc 关闭、批量卡片「2 张成功 · 1 张失败」逐图文案均正确；应用内真实会话未执行。

### S10 多变体不覆盖

- **点什么**：同一 prompt 连画两次 3 张变体（或批量里同名 `nameHint`）。
- **该看到什么**：已有文件保留，新文件落成 `-v2`/`-v3`，文件总数只增不减。
- **修复前是什么**：同名文件直接覆盖，第二次生成把第一次吞掉。
- **本轮**：`saveImage` 用 `wx` 独占创建 + 版本号重试，单测覆盖；未真实连画两轮。

### S11 改图

- **点什么**：给 Agent 一张本地图 + 「改成……」，允许后再看结果。
- **该看到什么**：OpenAI 方言走 `/images/edits` multipart；智谱方言明确拒绝且**不偷偷重新生成**；参考图数量写进卡片。
- **修复前是什么**：改图被静默降级成文生图，用户拿到一张与参考图无关的新图。
- **本轮**：OpenAI multipart 与智谱拒绝均有单测；真实改图未执行（自有端点是否支持 edits 未知，智谱真机需要 zhipu key）。

### S12 取消 / 批量

- **点什么**：批量 8 条 prompt 生成中点「停止」。
- **该看到什么**：在途请求中止、未开始的排队项丢弃、已画好的图保留；报告里 `cancelled` 与 `failed` 分开，卡片分别显示「已取消」「失败」；全取消时返回取消结果而不是通用失败。
- **修复前是什么**：停止只停引擎，子请求继续跑完并继续计费；已完成与未完成混在一起。
- **本轮**：网关三入口（中止/停止/挂起）+ 进程退出 + MCP 停止统一取消，单测覆盖；原型验证了批量卡片的成功/失败逐图文案；真实会话取消未执行。
