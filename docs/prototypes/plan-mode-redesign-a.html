1背景

设置页目前切换主题后只能整页生效，用户无法在应用前对比效果。目标：提供低成本的主题预览能力。

2方案概述

  • 预览范围：设置页 + 侧栏（沿用会话内 data-theme 切换，不触碰窗口层级）
  • 生效方式：悬停即时预览，移出还原，点击才落盘 themeStore

3实现步骤

1
抽取 PreviewScope 容器组件

将 data-theme 隔离到子树，避免全局副作用；落在 src/components/settings/

2
设置页主题卡接入悬停预览

mouseenter 预览 / mouseleave 还原 / click 提交，复用现有 4 套主题枚举

3
侧栏跟随预览

通过 CSS 变量作用域把预览扩展到 Sidebar，不引入第二个主题源

4
补测试

themeStore 单测 + 设置页预览交互测试，走 test:changed

4测试与风险

  • 风险：预览期间用户切换会话 → 用 PreviewScope 卸载钩子强制还原
  • 风险：anthropic-dark 与 dark 色板差异小 → 预览缩略图加名称标签区分
