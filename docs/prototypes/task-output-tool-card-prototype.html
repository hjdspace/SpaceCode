TaskOutput 工具卡片原型

TaskOutput 工具用于获取后台任务（Shell/Agent/Remote）的输出。当前桌面端未实现专属 UI 卡片，展开后仍显示原始 JSON 输入和 XML 输出文本。 本原型根据引擎端 TaskOutputTool.tsx 的数据结构，设计专属卡片 UI，根据 task_type 和 retrieval_status 渲染不同样式。

严重程度：高

2. UserService.ts — 未捕获异常

严重程度：中
第 78-92 行的数据库查询未包裹 try-catch，异常会直接传播到路由层。
建议：添加 try-catch 并返回结构化错误响应。

3. AuthController.ts — SQL 拼接

严重程度：低
第 112 行使用字符串拼接构造 SQL，虽然输入有过滤但仍存在风险。
建议：改用参数化查询。
