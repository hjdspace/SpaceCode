## SpaceCode v0.8.11

本版本两条主线：**计划模式与子代理（Agent）体验成型** —— 计划模式换上卡片同构的新 UI（问答卡 + 计划卡），pi 装上权限闸，未确认的计划拦得住消息；子代理可被会话选用、切换并被定时任务引用。同时落地 Pi MCP 服务器管理、Bash 实时输出流、会话文件变更追踪与思考力度全链路，并把引擎不可用错误统一收口。

## Highlights

- **计划模式新 UI**：方案 A 卡片同构 —— 问答卡支持描述型选项、Other 自由输入双帧流程、分页与跳过、可折叠摘要；计划卡全文 Markdown 渲染、目录锚点、默认渐隐折叠与一键复制
- **计划模式权限闸**：pi 装上权限闸扩展，计划未确认生效就拦住消息；行动菜单接入本地化与引擎重试 (#45)
- **子代理体系**：会话可选用并切换 agent（按 sessionId 定向，落不上会如实报错），应用状态经 agentNotice 通知；定时任务支持 agent 判定与状态回传；移动端支持 set_agent
- **扩展对话卡**：ExtensionDialogService 统一管理 pi 扩展 UI 请求，IPC/H5 全链路可应答，等待时通知用户
- **Pi MCP 管理**：MCP 服务器状态读取与启停（getPiState / setPiServerEnabled），配置变更经投影层同步到引擎，探测服务兜底校验
- **Bash 实时输出**：ShellOutputStream 让终端卡片边跑边出字，live 输出自动截断，缓冲型命令给出提示
- **会话文件变更追踪**：file write ledger 记录本次会话写过的文件，任务面板展示改动明细与「仓库外」标识，支持 diff / review / 统计查询
- **思考力度全链路**：effort level 类型标准化，引擎、网关、H5 与定时任务统一校验
- **侧任务**：上下文仅注入首条 prompt，transcriptDigest 提炼摘要，侧任务会话与临时上下文文件自动管理
- **历史会话**：按 engineType 恢复与展示，列表新增引擎徽标；Pi 会话历史恢复层支持 ephemeral 会话
- **pi 加固**：最低版本升至 1.1.0，按版本下限 fail-closed，打包态只跑自带的 bundled pi (#52)
