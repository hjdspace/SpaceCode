## SpaceCode v0.7.3

本版本核心聚焦于 Skill Manager V2 的完整重构与功能落地，涵盖 Agent 技能同步管理、诊断引擎、快照导出、技能包管理、GitHub 克隆导入与市场功能，同时优化了技能市场页面布局与体验。

## Highlights

- **Skill Manager V2 完整重构**：完成技能管理器 V2 的全面重构，实现 Agent 技能同步管理全功能，包括诊断引擎、Agent 详情展示与快照导出
- **GitHub 克隆导入与市场功能**：实现技能的 GitHub 克隆导入和市场浏览，增强技能导入与冲突处理能力（hash 冲突检测、预览/执行）
- **技能包管理**：新增技能包管理功能与拷贝同步，支持 Slice 4（分发）和 Slice 5（扫描与采纳）全流程
- **技能市场页面优化**：重构技能市场页面布局与体验，扩展内置 agent 注册表并优化 Agent 图标展示
- **按工作目录加载技能**：chat 面板支持通过 slash commands 按工作目录加载技能
- **右侧面板联动**：新增右侧面板联动环境卡片显隐的逻辑
- **CLI 图标更新**：新增 Kilocode 和 Trae 的 CLI 图标，更新 Copilot 图标

## Fixes

- 修复技能接管与共享目录扫描问题
- 修复 Agent 管理页 i18n 缺失、图标与版本号检测
- 兼容 electronAPI 不存在的场景，添加安全回退
- 优化信息面板显示逻辑并完善终端主题与测试

## Refactor

- 替换旧技能管理器为 V2 版本并添加关闭功能
- 移除任务列表卡片组件及关联逻辑
- 重构终端主题与启动参数逻辑，新增单元测试
- 重命名测试文件从 slice-based 为描述性名称
