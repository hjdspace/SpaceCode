## SpaceCode v0.8.6

本版本聚焦思考模式体验升级与稳定性修复：支持多端思考模式与流式 thinking 块的增量节流更新，新增引擎内部重试提示与本地 HTTP 预览服务器，并修复诊断状态计算与 Windows 用户模型 ID 区分问题。

## Highlights

- **思考模式**：支持多端思考模式，流式 thinking 块采用增量节流更新，思考过程展示更流畅
- **信息面板**：新增全屏功能与拖拽交互，浏览体验更佳
- **引擎重试**：实现引擎内部重试提示及相关逻辑
- **本地预览**：新增本地 HTTP 预览服务器，解决 file:// 协议的 CORS 问题
- **工具函数**：新增防抖节流通用工具函数

## Fixes

- 修复 traceViewModel 诊断状态计算问题
- 修复 Windows 环境下生产与开发应用用户模型 ID 未区分的问题

## Refactor

- 移除工作流功能相关代码和资源
- Linux worktree 文件监听迁移至 worker thread 实现，并为 GitService 文件监听生命周期补充测试

**Full Changelog**: https://github.com/hjdspace/SpaceCode/compare/v0.8.5...v0.8.6
