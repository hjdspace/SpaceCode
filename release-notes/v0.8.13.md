本版本交付「生成式 UI 卡片」：模型可以在对话里直接产出一张可交互卡片（参数表单、筛选条件、选项确认、结构化展示），SpaceCode 在隔离沙箱里渲染它，填写结果能提交回对话并随会话持久化。同一份技能说明同时喂给 Claude Code 与 Pi，桌面与 H5 两条承载链路都可用。

## Highlights

- **卡片渲染**：回复里的 ```` ```schemaJson ```` 围栏被投影成卡片，按官方 OpenTiny mini 物料渲染，跟随应用明暗主题与语言
- **隔离承载**：卡片跑在 opaque origin 的沙箱文档里，只有 `allow-scripts`；读不到父文档、读不到宿主存储、`connect-src 'none'` 断掉一切外联
- **四个动作**：卡片只能请求 `submit` / `copy` / `expand` / `openLink`，外链仅放行绝对 `http:` / `https:`；其余消息在桥口被丢弃，不转成通用 IPC
- **提交回环**：提交结果进入模型上下文并随会话保存，卡片随之转只读并留下可读摘要
- **生命周期与配额**：单条消息最多 8 张卡、单卡 schema 64KB、会话卡片预算 512KB；超限的卡片以可见占位退出，不阻塞会话打开
- **H5 可用**：远程访问下卡片由第二个只读静态端口承载，反向代理与隧道下源由服务端逐响应给出（部署与排查见 `docs/genui-h5-sandbox-deployment.md`）
- **技能单源分发**：`genui-card` 技能由构建期从当前安装的物料生成一份 `SKILL.md`，Claude 与 Pi 读同一份文本；物料升级未重新生成会在测试里失败
- **打包收口**：沙箱产物随安装包交付，安装后从应用目录经自定义协议加载，不依赖开发服务器；调试件与开发期沙箱服务都不进生产产物

## 已知残余风险

发布前审计（`docs/genui-release-acceptance.md` §6）明确接受的几条，写在这里以免被当成缺陷重复上报：

- **H5 端只有跨 origin，没有进程隔离**：卡片与主服务同 site，恶意卡片的死循环会拖住同一渲染进程。桌面端由 OOPIF 隔离，H5 按产品范围明确排除。
- **沙箱源允许 `unsafe-eval`**：卡片协议用 `new Function` 求值 `JSExpression`，是官方物料的运行前提。该授权只落在沙箱这一个源上，主窗口与 H5 父页面的 CSP 都不放开。
- **H5 第二端口不带鉴权**：它服务的四个文件就是构建产物本身，公开可读。不要往 `dist/genui-sandbox/` 放任何私有内容。
- **产物预览（DesignPreview）桥已按 [#62](https://github.com/hjdspace/SpaceCode/issues/62) 收口**：回传带每实例密钥并校验来源，动作走白名单，外链仅放行 `http:` / `https:`（主进程 `shell:openExternal` 同口径兜底）；`sandbox` 去掉 `allow-downloads`，保留的 `allow-scripts` / `allow-popups` 理由见 ADR 0017。
- **产物预览页脚本已可执行（[#63](https://github.com/hjdspace/SpaceCode/issues/63) / ADR 0018）**：桌面预览 iframe 改由 `spacecode-preview://artifact` 专用源承载，inline / external / module 脚本、相对资源与同源 fetch 正常执行；流式更新经 MessageChannel 注入，不再整页重载。宿主 CSP 的 `script-src` 保持 `'self'`，`frame-src` 只增加这一个精确源。H5 设计预览仍是静态 srcdoc。
- **预览登记根可能覆盖整个工作区**：design 模式选过项目目录时，产物脚本能读取同工作区内的白名单类型文件；不要在含敏感文件的目录里预览不可信产物。
- **打包后的 `frame-src` 仍含本机开发源**（`http://localhost:5174`）：主窗口与 H5 共用同一份 `index.html`，按打包态分叉 CSP 需要改构建注入；缓解因素是主进程只放行精确的卡片文档 URL，卡片 iframe 也拿不到别的源。
- **主窗口未注册 `setWindowOpenHandler`**：design 打印预览与"在资源管理器中打开"依赖 `window.open`，一刀切拒绝会伤既有功能；卡片链路本身因沙箱属性不含 `allow-popups` 而无法开新窗口。
