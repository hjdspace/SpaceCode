## SpaceCode v0.8.2

本版本聚焦于聊天交互体验升级与基础设施现代化，新增思考等级切换、消息编辑重发、欢迎页、流式代码展示等核心功能，同时完成 Vitest 测试迁移与字体系统统一。

## Highlights

- **思考等级切换**：新增思考等级切换能力，完善 H5 与桌面端会话控制
- **消息编辑重发**：新增消息编辑重发功能，重构 IPC 通道管理
- **WelcomeHero 欢迎页**：新增欢迎页组件，含默认任务列表与空会话集成，支持中英双语
- **流式代码展示**：新增 StreamingCodeBlock 组件用于实时代码流式渲染，替换原有预览区
- **模型选择持久化**：增强模型选择与持久化，支持 lastSelectedModel 记忆与初始化恢复
- **思考状态指示器**：新增 LLM 响应等待指示器与起始时间追踪
- **i18n 命名空间化**：locale 文件命名空间化改造并新增 key 一致性测试
- **代理配置增强**：新增 buildProxyConfigFromSettings 及代理配置同步逻辑
- **会话 hydration 增强**：增强消息 ID 追踪与时间戳保留，提升会话恢复可靠性

## Fixes

- 修复路径格式问题导致的重复项目组与打开失败
- 调整权限参数处理逻辑

## Refactor

- 替换全局字体为 Inter 与 Noto Sans SC 并统一排版变量
- 提取 yaml frontmatter 解析逻辑为独立模块
- 清理 src/ 中的无用代码空间
- 重构 ReadToolCard 与 EditToolCard 改善文件内容处理与 diff 展示
- 更新正文行高与 Markdown 排版间距
- 将默认字号从 14 调整为 15 并添加迁移逻辑
