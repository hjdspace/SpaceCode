## SpaceCode v0.8.14

本版本交付「工厂（Factory）」：把「领取任务 → 隔离工作树 → 实现 → 验证 → 审查 → 合并」整条流水线搬进桌面端，可用本地待办或 GitHub Issues 作为任务源，支持并发运行、暂停继续、接管与崩溃恢复。同时补齐 MCP 本地运行时探测、引擎会话预热、粘贴附件与暗色主题下的原生下拉框。

## Highlights

- **工厂看板**：六泳道看板按阶段呈现任务，支持多运行标签页、泳道聚焦、新建运行与运行停止确认；配置由初始化向导完成，可配置阶段、角色模型与并发数
- **流水线全链路**：每个任务在独立工作树里跑实现与验证，审查阶段可提意见并触发修复重跑，最后经合并闸门落地
- **任务源**：支持本地待办与 GitHub Issues，登录后可列举仓库并按并发批量领取；合并结果回写 Issue，避免重复领取
- **交付模式**：支持本地合并与 PR 模式（推送任务分支并创建 Pull Request），并提供 Docker 沙箱的单任务端到端模式
- **任务规划**：新建运行时可先做任务规划，产出候选任务、依赖关系与警告，超过单次上限的任务会提示
- **接管与恢复**：任意任务可接管到聊天面板继续对话，交回时做验证；进程崩溃后能恢复运行状态，接管面板支持 429 自动重试
- **观察面板**：卡片上直接显示当前动作行，只读观察面板复用聊天链路展示过程消息，不干扰接管
- **MCP 本地化与诊断**：内置 MCP 预设按界面语言本地化安装；本地运行时探测会识别 package manager launcher 与 Windows 命令包装，设置页显示生效命令与运行错误
- **会话预热**：桌面启动时预热引擎会话，新增 warmed 标识与空闲回收；思考态新增 starting 变体并在 MCP 启动失败时给出提示
- **粘贴附件**：长文本粘贴会落盘为附件，附件卡片支持悬停预览与元信息；超长提示词外置到会话临时目录
- **通知定位**：点击系统通知可直接定位并展开对应会话

## Fixes

- 修复残留分支与残留目录导致任务无法领取
- 修复 GitHub 登录轮询导致的进程堆积与状态不同步
- 修复接管交回挂死与实现阶段授权停摆
- 修复接管续话、观察同步与 Windows 交回验证
- 合并同任务并发领取，避免误报 worktree-busy
- 移除接管面板重复显示的任务目标
- 预览 iframe 收紧 sandbox 属性并移除 `allow-popups`，外链与 alert 行为收敛到沙箱 shim
- 修正 Windows 上 cdp-bridge.exe 与跨平台路径处理
- 原生 `select` 按主题声明 `color-scheme`，修复暗色主题下下拉弹层选项不可读
- 修复子进程启动失败时的进程归属
- 降低流水线长运行的内存与日志开销
