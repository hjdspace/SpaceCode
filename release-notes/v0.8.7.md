## SpaceCode v0.8.7

本版本以定时任务与通知链路的重构为主线：定时任务执行改为可见的引擎真会话并支持自定义工作空间、模型与图片附件；会话等待回答或授权时会即时弹出系统通知。同时新增侧边任务面板、文件树 Git 状态标记与内置技能包能力。

## Highlights

- **定时任务**：任务可配置工作空间、分支、模型、权限模式与图片附件；执行不再是隐藏子进程，而是起一个可见的引擎会话，跑完可原地续聊
- **系统通知**：AskUserQuestion、工具授权、ExitPlanMode 三类中断即时通知，新增「等待处理桌面通知」开关（默认开启），并补任务栏闪烁兜底
- **侧边任务面板**：新增 SideTaskPanel 紧凑对话面板，选中文本可直接发起侧边提问，与主会话并行使用互不串扰
- **变更卡片**：TurnChangeCard 支持悬停 Diff 弹窗与文件列表折叠
- **文件树**：新增文件类型图标，并集成 Git 状态标记（M/U/A/R/D/C）
- **技能库**：新增内置技能包页面与批量安装、技能分类过滤，收录 AI Berkshire 投研技能库与 matt-skills 技能包
- **图片输入**：用户消息中的图片支持转换为内联图片块

## Fixes

- 修复定时任务不触发：任务表与引擎共用文件被互相清理、调度器项目根从未赋值导致每分钟直接返回
- 修复定时任务执行成功却被收尾异常改写成报错
- 修复任务配置的模型被静默丢弃，实际跑的是全局默认模型
- 修复时间滚轮滚动卡顿：面板内滚动不再触发浮层重定位，改为点「确定」才提交
- 修复开发态系统通知导致任务栏图标回退为 Electron 默认图标

## Refactor

- 全局滚动条统一为 scrollbar-overlay mixin（代码查看器、Diff、Markdown、Agent 时间线等）
- TurnChangeCard 悬停弹窗渲染引擎替换为 DiffView，并修复弹窗内部滚动误关闭
- 权限模式切换引入重试逻辑；模型目录补充 input / capabilities 字段与更强的模型 ID 匹配
- 移除聊天头部模型徽章
