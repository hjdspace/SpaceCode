## SpaceCode v0.7.6

本版本聚焦前端体验优化与架构加固，新增斜杠命令消息的 inline chip 渲染、IPC 通道类型安全增强，以及子进程生命周期管理模块。

## Highlights

- **斜杠命令标签**：聊天消息中斜杠命令现在以 inline chip 形式渲染，视觉更清晰，交互更直观
- **类型安全 IPC**：为 git 命名空间引入 typed channel map，单一事实来源，减少运行时错误
- **子进程生命周期管理**：新增 Electron 子进程管理模块，完善生命周期与配套测试覆盖

## Fixes

- 修复 DiffViewer 行内容宽度显示异常
- 修复 createRendererApi 返回 Proxy 导致 spread 后丢失方法的问题
- 修复 CSP 缺少 media-src 指令导致媒体资源加载失败

## Performance

- 合并后台积压的 text_delta 写回，避免恢复窗口时逐条刷新

## Refactor

- 提取 syncPermissionMode 与 useRewindDialog 深模块，降低 chatSession 复杂度
- 统一技能管理的分类与安装逻辑，提升可维护性
- 重构 config setters 为不可变更新

**Full Changelog**: https://github.com/hjdspace/SpaceCode/compare/v0.7.5...v0.7.6
