## SpaceCode v0.8.12

本版本带来语音输入与生成式 UI 卡片两条全新链路，并补上运行时模型切换、CLI 更新检查与设计预览交互改进。

## Highlights

- **语音输入**：识别模型安装、校验与设置页管理，流式识别会话与音频通道，输入框听写支持采音、实时转写与终稿提交，Alt+V 可在最近聚焦的输入框直接开始听写
- **生成式 UI 卡片**：桌面卡片沙箱承载与 nonce 握手，卡片渲染真实内容，卡片动作相互隔离
- **提示词优化**：输入框新增提示词优化入口与交互
- **运行时模型切换**：会话内可直接切换模型（Pi setModel），会话配置新增可选模型列表与 reasoning 能力，思考力度按引擎类型注入
- **CLI 更新检查**：设置页新增 CLI 更新检查与修复流程，检查结果带缓存与失效重检
- **设计预览**：设计系统选择器支持预览缩放与弹窗，预览面板按需弹开
- **语言即时切换**：引导向导与设置里的语言选择即时生效，无需重启

## Fixes

- AudioWorklet 处理器改为同源静态文件加载，避免跨源加载失败
- 补齐录音失败路径的状态收口与重试
- 修复语音录制模式下输入框空态显示异常
- 修复切换工作区后聊天页目录不同步
- 模型切换失败与 CLI 更新检查补充明确错误提示

## Refactor

- Pi 事件过滤函数参数收敛，进程池日志输出规则优化
- 会话可切换模式按 engineType 重构
- 临时产物目录按 uid 收紧目录与文件权限
