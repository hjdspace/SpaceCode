## SpaceCode v0.8.1

本版本重点增强聊天工具调用体验，新增子代理面板、会话缩略图、模型切换优化及自动更新器改进。

## Highlights

- **工具调用折叠分组**：新增工具调用折叠分组组件，支持加载中与思考状态展示，重构工具事件展开动画并增强摘要 chips 展示
- **会话缩略图**：新增 Conversation Minimap 组件，提供会话全局缩略视图，附带 i18n 支持
- **子代理面板**：新增 SubagentPanel 组件，集成至 InfoPanel 提供子代理交互详细视图，支持状态管理与运行指示器
- **模型切换增强**：switchModel 支持选项参数与 displayModel 显示，会话接口新增 model 字段，上下文用量逻辑使用会话模型，ChatPanel 模型变更处理增强
- **InfoPanel 加载优化**：InfoPanel 改用异步组件加载与预加载策略，提升面板加载性能
- **工具状态运行中支持**：工具调用状态支持运行中（running）状态展示
- **自动更新器改进**：生产环境参数化传递 GitHub token 至 autoUpdater，提升安全性
- **项目路径提取**：从会话消息中提取真实项目路径

## Fixes

- 修复 overallStatus 计算属性中 isStreaming 条件判断错误
- 为 setModel 控制请求添加超时处理，避免请求卡死
- 改进 MarkdownRenderer 文件链接验证逻辑

## Refactor

- 重构 AgentToolCard 组件
- 重构 turn store 模型获取逻辑
- 重构子代理面板状态管理
- Vite 配置使用 import.meta.dirname
- 重构 MarkdownRenderer 文件链接增强
