## SpaceCode v0.7.2

本版本重点完善了 Skill Manager V2 的核心功能，并修复了 Linux 平台的打包与运行适配。

## Highlights

- **Skill Manager V2**：实现技能库页面、搜索、分页、导入中心库三大核心功能，包括基于 hash 的冲突检测和预览/执行流程
- **Linux 平台适配**：完善 Linux 平台的打包与运行支持，提升跨平台体验
- **启动闪屏**：开发模式下添加启动闪屏窗口，优化启动视觉反馈

## Fixes

- 优化 Electron 窗口显示逻辑和代理健康检查日志
- 将 ChatPanel 改为同步导入以避免加载延迟
