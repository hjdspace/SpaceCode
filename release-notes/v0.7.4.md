## SpaceCode v0.7.4

本版本继续完善 Skill Manager V2，新增 Agent 概览、技能详情文件浏览与直接分发能力，并修复技能分发和托管目标扫描中的稳定性问题。

## Highlights

- **Agent 概览与技能管理**：新增 Agent 概览页签，展示 Agent 状态、配置完整度和能力快照，并支持技能包快速应用与取消应用
- **技能详情文件浏览**：在技能详情中新增可折叠文件树，支持预览与源码切换查看
- **Agent 分发管理**：支持从技能卡片进入详情并直接分发技能，同时完善批量删除和单分发管理交互

## Fixes

- 修复链接目标被复制目录替换后的分类问题，并清理数据库中过时的托管目标记录
- 修复 Electron IPC 无法结构化克隆 Vue 响应式对象的问题，同时改善相关页面的布局溢出与响应式适配

**Full Changelog**: https://github.com/hjdspace/SpaceCode/compare/v0.7.3...v0.7.4
