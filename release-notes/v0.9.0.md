## SpaceCode v0.9.0

本版本正式交付「Super Agent」：一个能托管多张并行工单的桌面工作台——与 Router 对话、显式派工，Worker 在后台独立执行，可随时只读观察并接管；同时接入飞书 IM 与 GitHub PR，让工单由外部事件驱动、结果回写到外部信道。另完成一轮显著的首载与样式减重。

## Highlights

- **Super Agent 工作台**：Router 与 Worker 双角色协作，Router 复用主聊天输入框与时间线；普通对话只与 Router 交流，建单走独立的显式派工动作
- **工单生命周期**：单行工单卡片跟随排队、执行、待验收、提问、阻塞、失败与完成等阶段，支持接受验收、继续追问、停止与重试，超时只提醒不自动完成
- **Worker 观察与接管**：右侧面板以只读时间线实时呈现 Worker 的工具调用、流式输出与产物，按代次分段；接管后时间线可交互输入，交还恢复自动推进
- **Attention 问答**：Worker 提问以非模态气泡呈现，就地回答并保留审计，同一问题只提醒一次
- **执行策略**：默认串行调度，可显式开启并行并强制 per-ticket worktree；Worker 权限档位与授权策略设置面板
- **外部 Source**：飞书 IM 群消息与 GitHub PR 可成为 Trigger，支持 @ 建单候选、上下文订阅、订阅 fast path 与 follows 绑定；PR 评审闭环可唤醒 Worker 并静默 resolve 已修复的评论
- **Outbox 回写**：回答、结果与进度经受控 reply 回写桌面、飞书与 GitHub 通道，可追溯到 Worker 认领过的人问题
- **可靠性与健康**：项目状态原子持久化与崩溃恢复，退出时有界收尾；系统问题只读面板与两级 Eval、Policy 版本化
- **加载态统一**：聊天思考态统一为 LoadingState，活动标签与时长展示一致
- **体验细节**：提示词优化按钮移至输入框右上角，右面板默认加宽至 560px，设计系统下拉支持创建与删除自建项
