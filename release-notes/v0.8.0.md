## SpaceCode v0.8.0

本版本核心交付了全新的 **会话编排引擎 (Session Orchestration)** — 基于 DAG 状态机与 Vue Flow 无限画布，支持节点编排、依赖连线、运行流水线、失败重试与状态恢复。同时优化了聊天消息交互与多项修复。

## Highlights

- **编排引擎核心**：DAG 状态机 + turn 结局订阅点，为多节点编排提供底层调度能力
- **Canvas Shell**：编排中心 Tab + Vue Flow 无限画布，可视化拖拽编排会话节点
- **Task Node + Draft + Drawer**：缩略聊天节点卡片、草稿模式与放大抽屉面板
- **Edge 连线 + 环预防**：节点间依赖连线编辑与即时成环检测拒绝
- **Run Pipeline**：引擎接线、连接池（20）、运行状态徽章与进度展示
- **Failure & Run Control**：节点停止、重试、追加消息、权限路由
- **Run 状态恢复**：运行快照持久化，重启后如实展示运行状态
- **节点卡片重构**：重构节点卡片与抽屉，新增迷你聊天面板与状态展示
- **用户消息复制**：新增聊天消息复制功能并重构操作栏交互
- **右键菜单优化**：右键菜单定位优化，增加视口边界夹紧逻辑
