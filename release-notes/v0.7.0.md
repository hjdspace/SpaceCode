## SpaceCode v0.7.0

本版本为桌面宠物带来全面重构：采用 Sprite Atlas 帧动画方案替代 SVG，新增 4 只内置宠物、9 状态 + 16 方向视线动画与任务监控状态映射；移动端新增文件浏览器与代码预览能力；同时新增 Tavily 免费代理搜索并修复多处稳定性问题。

## Highlights

- **桌面宠物 Sprite Atlas 重构**：采用 Sprite Atlas + CSS `background-position` 帧动画（PetSpriteAtlas.vue）替代旧版 SVG 实现，渲染更流畅、资源更紧凑
- **多状态动画与视线追踪**：9 种状态动画 + 16 方向视线追踪（petAnimation.ts），宠物随鼠标位置自然转头
- **任务监控状态映射**：petSessionModel 将 SpaceCode 的 chatSession/turn store 映射为 5 状态模型（idle / thinking / acting / waiting / done），由 pet.ts store 聚合并经 IPC 推送至宠物窗口，AI 干活时宠物同步卖萌
- **多只内置宠物**：4 只独立精神图绘，设置面板（PetSettings.vue）支持宠物选择与尺寸 / 动画 / 任务面板开关
- **透明置顶窗口**：透明顶层窗口，16ms 光标采样拖拽，面板边缘翻转带 24px 滞回区间，区域穿透不挡操作（petWindowManager.ts）
- **移动端文件浏览器与预览**：新增 file_explorer_service.dart / file_explorer_screen.dart / file_preview_screen.dart，目录树展开折叠、文件点击进入主页面预览，支持代码高亮与 Markdown 渲染，顶部面包屑路径快速跳转
- **Tavily 免费代理搜索**：新增 Tavily 免费代理搜索支持并优化搜索错误展示

## Fixes

- 修复多宠物状态同步问题
- 优化 Electron 进程池方法的空进程处理逻辑

## Refactor

- 重构桌面宠物系统，移除旧版反应逻辑与冗余代码（清理 42 个旧 SVG / composable / LLM 代理 / 测试文件）
