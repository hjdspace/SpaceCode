# 提示词写法参考

正文里的模板是骨架，这里给按用例的具体化方式。共同原则：**用户没说的不要加**。

## 用例 slug

| slug | 典型诉求 | 必须交代清楚的 |
| --- | --- | --- |
| `photorealistic` | 产品图、场景照 | 镜头（焦距/景深）、光线方向与色温、材质、背景 |
| `illustration` | 插画、封面 | 媒介（水彩/矢量感/厚涂）、线条、配色、构图留白 |
| `ui-mockup` | 界面稿 | 设备与画幅、层级、真实文案、控件密度、配色主题 |
| `sprite` | 游戏素材 | 视角（俯视/侧视）、朝向、尺寸、纯色背景、单个对象 |
| `texture` | 贴图、材质 | 平铺可无缝、无方向性光照、尺度参照 |
| `banner` | Banner、封面 | 画幅比例、文字原文与位置、主体避让区 |
| `infographic` | 信息图 | 分区数量、每区原文、层级顺序、图标风格 |
| `product-shot` | 电商图 | 背景（纯色/场景）、投影、角度、是否带包装 |

## 逐项写实的要点

**画幅**：先想清楚用在哪。Banner 用宽幅、封面用竖幅、图标用方形。
`size` 只在供应商支持时生效，不支持时以工具返回的实际尺寸为准。

**文字**：模型写文字容易出错。给原文时：
- 用双引号包住，标注语言与大小写；
- 说明位置（左上/居中/底部）与字体气质（无衬线粗体、手写体）；
- 生僻词逐字母拼出来；
- 文字越少越准，长段落改成短句。

**风格**：说媒介和技法，不要堆艺术家名字，也不要提任何品牌。
「水彩，湿边，冷灰蓝配色」比「像某某画的」可控得多。

**约束**：把「不要什么」写进 Constraints，比在正文里绕着说有效。
例如「无人物、无文字、无水印、背景纯色」。

## 本期能力边界带来的写法调整

- 没有改图工具：用户给了参考图时，把参考图里要保留的要点用文字写进提示词，
  并明确告诉用户这是**重新生成**，不是在他们那张图上改。
- 一次一张：需要一套资产时，逐张调用、逐张写提示词，并在报告里说清共几张。
  不要试图用一个提示词让模型画出一整版九宫格再自己裁。
- 没有透明背景：要抠图素材时，改成「纯色背景（如纯白/纯品红），主体边缘清晰、无投影」，
  并说明透明需要用户自行处理。
